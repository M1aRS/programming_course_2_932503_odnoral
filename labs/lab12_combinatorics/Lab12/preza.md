# Иллюстрация алгоритма генерации перестановок
## Лабораторная работа №9 (Упражнение 1)
### Мощность множества n = 3

---

### Исходный код

```cpp
№1 #include <iostream>
№2 using namespace std;

№3 int *P, *R, n;

№4 void per(int k) {
№5  for (int i = 1; i <= n; i++) {
№6      if (R[i] == 0) { 
№7          P[k] = i; R[i] = 1;
№8          
№9          if (k == n) { 
№10              for (int j = 1; j <= n; j++) cout << P[j] << " ";
№11              cout << endl;
№12          } else per(k + 1);          
№13          R[i] = 0;          
№14      }
№15  }
№16 }

№17 int main() {
№18     n = 3;
№19     P = new int[n + 1]; 
№20     R = new int[n + 1]{0};
№21     per(1);
№22     return 0;
№23 }
```

### Шаг 5: Возврат (Backtracking) в per(2)
Завершили `per(3)`, обнулили `R[3]`. В `per(2)` цикл `i` идет дальше. i = 3.

| Статическая память | Стек (Вызовы) |
| :--- | :--- |
| **n** = 3 | **per(2)** (i=3) |
| **P** = [1, **3**, ?] | **per(1)** (i=1) |
| **R** = [1, 0, **1**] | **main** |

*Заметьте: R[2] теперь 0, а R[3] стал 1.*
